# Software Asset Registry

This repository hosts the Nimbus Technologies software asset registry.

## Structure
- `catalog.json` - list of candidate asset identifiers
- `metadata/<id>.json` - machine-readable metadata record per asset
- `docs/<id>.md` - human-readable documentation page per asset
- `reports/` - compliance review reports published back to the registry
